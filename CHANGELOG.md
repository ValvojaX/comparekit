# Changelog

## 0.1.0

First release.

- Compare and 3-way merge for CSV/TSV tables and Excel workbooks (cell by cell), images, ZIP archives (entry by entry) and other binary files.
- Folder compare, with same-size files checked byte by byte.
- Git: compare a file or folder with any revision, open changes from Source Control, resolve merge conflicts in non-text files, compare branches and commits in the Compare Revisions view, and compare from the Timeline.
- Table viewer for Excel (default) and CSV/TSV (*Show as Table*).
- Explorer submenu with Select for Compare / Compare with Selected, and the selection shown in the status bar.
